项目说明

关于这个网站，以及让它成为可能的作品。

设计与代码

网站基于 Once UI 团队的 Magic Portfolio 改编， 使用 Once UI 组件。 在原作之上调整了博客归档、摄影排版、背景与交互，并加入本地内容工作室和静态发布功能。

本轮视觉改版参考 Moonshot AI 官网与 Kimi 的公开产品界面，以中性色、留白和清晰层级组织内容。 站点标记、页面排版与卡片样式独立实现。

博客结构参考 Anthony Fu； 背景交互参考 Codex 页面的字符尾迹， 以渐隐的等宽字符与柔和光晕回应鼠标移动，使用 CSS 与 Canvas 独立实现。 摄影标题的字体呈现参考 Horizon。 模板示例摄影来自 Lorant，通过 Magic Portfolio 提供。

诗词与节气

诗词笺收录 72 篇，保留 30 篇《诗经》，并选入汉魏六朝、唐宋及元明清的诗词。 唐宋原文参考 chinese-poetry， 其余篇目按所列古籍整理，每篇均附出处。原文以繁体呈现，标点及部分异体字作阅读整理， 荐语与简注为本站阅读提示。可按朝代、意境与简繁关键词检索，按北京时间每日轮换。 诗文采用本地加载的 Noto Serif TC 字形子集（SIL OFL 1.1），字体随站点提供。 节气、农历与传统物候由 lunar-typescript 计算。 物候沿用传统七十二候名称。两项数字资源均保留 MIT 许可与署名。

星野与传统星官

星表和中国传统星官连线取自 D3-Celestial 的数据集， 恒星原始资料来自 XHIP（扩展 Hipparcos 星表），传统星官数据源自 Stellarium。 保留 Olaf Frohn 的 BSD 3-Clause 许可及来源署名，星图绘制与交互由本站独立实现。 星位按所选城市和时间计算，适用于 1900—2100 年的肉眼星空示意； 古籍引文用于文化阅读，简注为本站整理。
