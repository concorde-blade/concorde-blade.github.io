项目说明

关于这个网站，以及让它成为可能的作品。

设计与代码

网站基于 Once UI 团队的 Magic Portfolio 改编， 使用 Once UI 组件。 在原作之上调整了博客归档、摄影排版、背景与交互，并加入本地内容工作室和静态发布功能。

博客结构参考 Anthony Fu； 全站水墨与星野交互的视觉参考来自 React Bits 和 Magic UI，使用 CSS 与 Canvas 独立实现； 摄影标题的字体呈现参考 Horizon。 模板示例摄影来自 Lorant，通过 Magic Portfolio 提供。

诗经与节气

诗经选读收录 30 篇，原文据 chinese-poetry， 选句句读略作调整，简注为本站阅读提示。按北京时间每日轮换，可翻阅往期。 节气、农历与传统物候由 lunar-typescript 计算。 物候沿用传统七十二候名称。两项数字资源均保留 MIT 许可与署名。
